# Auswahldialog: die Frage "Vorlage"

Teil von `dialog.md`. Nur lesen, wenn die Vorlage gefragt wird (Skill Baue-E-Learning, Vorlage nicht genannt).

**Vorlage** (Header "Vorlage"): nur wenn die Lehrkraft sie nicht genannt hat (z. B. "Lernschritte", "wie das Ethik-E-Learning", "Schriftfeld", "wie immer" = Schriftfeld). Zwei Optionen, jede mit einer kleinen Skizze als `preview`:
- `Schriftfeld (Fachunterricht.html)`, Beschreibung: "Eine lange Seite mit Schriftfeld, Kapiteln und Niveaus. Für Arbeitsblätter und Lernskripte."
  ```
  ┌──────────────────────┬─────────┐
  │ Titel                │ Beruf   │
  │ Untertitel           │ Jahr    │
  ├───────┬──────────────┼─────────┤
  │ LF·BW │ Hilfsmittel  │ Name    │
  └───────┴──────────────┴─────────┘
  Kapitel 1
   ▌Einsteigerniveau  [Aufgabe 1.1]
   ▌Prüfungsniveau    [Aufgabe 1.2]
  Kapitel 2 ... (alles untereinander)
  ```
- `Lernschritte (Allgemeinbildung.html)`, Beschreibung: "Schritt-Leiste, eine Bildschirmseite pro Schritt, Phasen mit Sozialform und Timer. Für Unterrichtsfolgen über mehrere Stunden."
  ```
  █ Logo  Titel                     █
  █ Beruf │ Jahr │ LF·BW │ Name     █
   (1)(2)(3)(4)(5)   Schritt-Leiste
   STUNDE 1 VON 3
   2 · Der Fall
   ▌EINZELARBEIT Fall lesen 12 Min [Timer]
   ╭ Karte ────────────────────╮
   │ Aufgabe 2.1 ...           │
   ╰───────────────────────────╯
   [Zurück]               [Weiter]
  ```
"(empfohlen)" bekommt bei Arbeitsweise B die Vorlage, die dem Original am nächsten ist (Original mit Schritt-Navigation, Stunden oder Phasen → Lernschritte, sonst Schriftfeld), bei Arbeitsweise A Lernschritte, wenn das Material Phasen, Sozialformen oder Zeiten über mehrere Stunden vorgibt, sonst Schriftfeld. Die empfohlene Option steht oben.
